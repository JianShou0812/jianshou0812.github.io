Abstract

Agentic robotics is emerging as a way to tackle long-horizon tasks by composing learned skills. In mobile manipulation, where the robot stops affects what a local policy sees and what the robot can reach. We present MovingVLA, a framework for instance-grounded skill scheduling. The planner uses task memory to choose the next interaction and binds it to an instance in scene memory. The same instance guides approach preparation and navigation. After arrival, the planner uses fresh observations to decide whether to invoke a frozen vision-language-action (VLA) policy or revise the approach. Feedback from local execution informs the next skill call. On RoboCasa365 Navigation20, MovingVLA raises task success from 51.83% to 70.0% with frozen Awomo-0.5I and from 10.7% to 53.5% with frozen RLDX-1. It also improves mean success over the corresponding standalone policies on six BEHAVIOR-1K tasks and four real-robot tasks. MovingVLA offers a way to extend advances in local robot skills to long-horizon mobile tasks. Code will be released.
